# Pathway Benchmark Helpers

This directory contains lightweight downstream analysis helpers used by the
paper figure pipeline.

Included scope:

- gene-level perturbation recovery summaries;
- pathway-restricted fit-vs-pathway diagnostics;
- pathway knowledge tables used by the figure scripts;
- plotting helpers for local analysis outputs.

Excluded scope:

- full historical benchmark outputs;
- private run directories;
- cached PNG dashboards;
- large prediction profiles.

Use `MVCPERT_DATA_ROOT` and `MVCPERT_ARTIFACT_ROOT` to point the scripts to
local data and prediction artifacts.

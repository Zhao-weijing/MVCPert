# Figure 4 Missing-Modality Virtual Profiling

This directory contains the lightweight Figure 4 assets.

Files:

- `scripts/generate_figure4_missing_modality_virtual_profiling.py`: figure
  generator.
- `scripts/figure4_latent_geometry_helper.py`: latent geometry helper.
- `outputs/figure4_bbbc047_missing_modality_virtual_profiling.pdf`: current
  Figure 4 PDF export.
- `outputs/figure4_missing_modality_training_schematic.pdf`: schematic asset.

External inputs:

- missing-modality prediction profile HDF5 files under `<ARTIFACT_ROOT>`;
- latent NPZ files under `<ARTIFACT_ROOT>`.

The large input files are not included in this GitHub package.

# Figure 5 Case Studies

This directory contains the lightweight Figure 5 case-study assets.

Files:

- `scripts/generate_figure5_case_studies.py`: figure generator.
- `outputs/figure5_bbbc047_case_studies.pdf`: current Figure 5 PDF export.

External inputs:

- baseline and MVCPert prediction profiles under `<ARTIFACT_ROOT>`;
- BBBC047 compound metadata, replicate tables, and gene map under
  `<DATA_ROOT>`.

The large input files are not included in this GitHub package.

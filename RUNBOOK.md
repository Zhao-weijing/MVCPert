# MVCPert Runbook

This runbook describes the lightweight GitHub release workflow. It focuses on
the core model and figure code rather than an exhaustive rerun of every
historical experiment.

## 1. Environment

Install the listed dependencies in any Python 3.11 environment:

```bash
python -m pip install -r requirements.txt
```

For GPU training, install a CUDA-enabled PyTorch build that matches your
machine before installing the remaining packages.

## 2. Data Layout

The release expects external data to be supplied by the user. A convenient
layout is:

```text
<DATA_ROOT>/
  BBBC047/
    Paired_CP_GE_Data_one_sample_per_molecule.h5
    Paired_CP_GE_Data.h5
    merged_repurposing.csv
    Step2_CP_cleaned.parquet
    Step2_GE_cleaned.parquet
    gene_map.csv
  BBBC036/
    Paired_CP_GE_Data_official.h5

<ARTIFACT_ROOT>/
  ... prediction profiles and checkpoints generated by training ...
```

Set paths through environment variables:

```bash
export MVCPERT_BBBC047_H5=<DATA_ROOT>/BBBC047/Paired_CP_GE_Data_one_sample_per_molecule.h5
export MVCPERT_OUTPUT_BASE=<PROJECT_ROOT>/runs
export MVCPERT_ARTIFACT_ROOT=<ARTIFACT_ROOT>
export MVCPERT_DATA_ROOT=<DATA_ROOT>
export MVCPERT_AIDD_ROOT=$PWD/source
```

## 3. Smoke Test

```bash
bash scripts/run_smoke.sh --dev cpu
```

The smoke configuration uses a small latent dimension and one epoch. It only
checks data loading, split handling, and model instantiation.

## 4. Main Training

```bash
bash scripts/run_mvcpert_main.sh --dev cuda:0
```

This invokes:

```text
source/baseline/src/train_mvc.py
configs/main_mvcpert_bbbc047_args.txt
source/baseline/artifacts/split_locks/BBBC047_smiles_split_seed3407_official_v1.json
```

Expected large outputs include checkpoints, prediction HDF5 files, latent NPZ
files, and CSV metric summaries. These are not part of the GitHub repository.

## 5. Downstream Analysis

Core analysis helpers are under:

```text
source/baseline/pathway_benchmark/
```

Important entry points:

```bash
python source/baseline/pathway_benchmark/evaluate_bbbc047_gene_level_downstream.py --help
python source/baseline/pathway_benchmark/diagnose_bbbc047_model_fit_vs_pathway_gap.py --help
```

## 6. Figures

```bash
bash scripts/regenerate_figures.sh
```

Notes:

- Figure 2 uses local `analysis/*.csv` by default.
- Figure 3 uses local `analysis/*.csv` for the lightweight release path.
- Figure 4 requires missing-modality prediction profiles and latent files.
- Figure 5 requires prediction profiles plus compound metadata and replicate
  tables.

## 7. Release Check

```bash
python scripts/check_release_ready.py
```

The checker blocks common privacy and repository hygiene problems, including
absolute private paths, large binary artifacts, caches, local run directories,
and internal agent instruction files.
